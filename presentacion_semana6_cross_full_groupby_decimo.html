CROSS JOIN

  

    
Sintaxis

SELECT columnas
FROM tabla1 a
CROSS JOIN tabla2 b
WHERE filtros;   -- opcional

      
    
        
  • Cada fila de la tabla 1 con cada fila de la tabla 2.
    • 
        
  • No lleva ON: no busca parejas FK = PK.
    • 
        
  • Filas = filas de 1 × filas de 2 (después del WHERE).
    • 
        
  • Igual a FROM tabla1 a, tabla2 b sin condición.
    • 
      

    

    
Ejemplo: paquetes entrenador–plan

SELECT e.nombre AS entrenador, p.nombre AS plan
FROM entrenadores e
CROSS JOIN planes p
WHERE e.especialidad IN ('Yoga', 'Cardio')
  AND p.nombre IN ('Mensual', 'Anual');

      
2 × 2 = 4 filas

¿Para qué sirve? Para generar combinaciones: tallas × colores, horarios × salones, entrenadores × planes.

Parte 2

  
FULL OUTER JOIN: no perder ninguna fila

  
Todas las filas de A y todas las de B, tengan o no pareja.







  
📓 para el cuaderno

  
FULL OUTER JOIN en MySQL

  

    
Así NO funciona en MySQL

SELECT s.nombre, e.nombre
FROM socios s
FULL OUTER JOIN entrenadores e
  ON s.entrenador_id = e.id;

      
Error 1064: You have an error in your SQL syntax… MySQL no tiene FULL OUTER JOIN.

    

    
Así sí: LEFT + UNION + RIGHT

SELECT columnas FROM A LEFT  JOIN B ON a.fk = b.pk
UNION
SELECT columnas FROM A RIGHT JOIN B ON a.fk = b.pk
ORDER BY columna;

      
    
        
  • Las filas con pareja salen en las dos consultas; UNION deja una sola.
    • 
        
  • UNION ALL no quita repetidas: las parejas salen dos veces.
    • 
        
  • Mismas columnas, mismo orden. ORDER BY solo al final.
    •

Parte 3

  
JOIN con GROUP BY y HAVING

  
Semana 1 + semana 5: contar y sumar mostrando nombres, no ids.







  
Paso a paso

  
¿En qué orden procesa MySQL la consulta?


SELECT p.nombre AS plan, COUNT(m.id) AS pagadas
FROM planes p
INNER JOIN membresias m ON m.plan_id = p.id
WHERE m.fecha_pago IS NOT NULL
GROUP BY p.id, p.nombre
HAVING COUNT(m.id) >= 2
ORDER BY pagadas DESC;

JOIN con GROUP BY y HAVING

  


SELECT t1.nombre, COUNT(t2.id) AS cantidad,
       SUM(t2.valor) AS total
FROM tabla1 t1
INNER JOIN tabla2 t2 ON t2.fk = t1.id
WHERE filtro_de_filas
GROUP BY t1.id, t1.nombre
HAVING filtro_de_grupos
ORDER BY cantidad DESC;

Ejemplom.fecha_pago IS NULLCOUNT(m.id) >= 2

    

  

  
    
    
  • Orden: FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
    • 
    
  • Toda columna del SELECT que no esté en COUNT, SUM, AVG… va en el GROUP BY.
    • 
    
  • Para ver los grupos con 0, LEFT JOIN + COUNT(columna_de_la_otra_tabla).
    • 
    
  • SUM y AVG ignoran los NULL; si todo el grupo es NULL, dan NULL.
